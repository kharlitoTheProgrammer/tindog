## 🐶 Tindog – A Tinder-Inspired Website for Dogs

Tindog is a simple, static website built to practice foundational web development skills using HTML and CSS. Inspired by the concept of Tinder, it presents a playful landing page for a fictional dating app for dogs.

This project focuses on clean layout structure, basic styling techniques, and introductory responsive design.

### 🔧 Features:
- Responsive layout built with HTML and CSS
- Clean, minimal design and user-friendly structure
- Emphasis on semantic HTML and consistent styling

Tindog represents an early step in my development journey and demonstrates my understanding of core front-end principles.
